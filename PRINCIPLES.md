# Compost Principles

1. **AI use is not the offence.** Compost does not infer authorship or shame people for using AI.
2. **Measure repetition, not identity.** Scores describe patterns in corpora, not the person who submitted text.
3. **A common phrase is not a bad phrase.** Prevalence is descriptive, not moral.
4. **A rare phrase is not automatically good.** Scarcity is not quality.
5. **Keep the denominator.** Every count must retain the population it came from.
6. **Separate prevalence, lift and momentum.** Do not collapse them into a mysterious single score.
7. **Contemporary humans matter.** A pre-AI baseline alone cannot distinguish AI influence from ordinary language change.
8. **Discovery must survive validation.** A pattern that only exists in the sample that discovered it is not a useful signal.
9. **Advice, never enforcement.** Future suggestions are optional; the writer remains in control.
10. **Privacy should be architectural.** Future Commons designs should minimise raw-text collection and make exposure controls structural rather than rhetorical.
11. **Do not overclaim identity guarantees.** Anonymous contributor counts are not proof of unique humans; Sybil resistance is a separate problem.
12. **Measure reflexivity.** If Compost eventually suggests alternatives, observations should record that provenance so the project can measure its own influence on language.
13. **Publish limitations.** The system should expose uncertainty, corpus bias and known failure modes rather than hiding them behind a score.

The project should be able to say, without contradiction:

> Nothing wrong with using AI. But a lot of other agents may have had exactly the same rhetorical epiphany this week.
